Ces guides valent pour **CSFML 3.0.0 et CSFML 2.6.1**. Quand le code diffère entre les deux versions, la page l'indique avec des onglets. Chaque affirmation technique vient d'un test réel ou d'un header ; ce qui n'a pas pu être vérifié est signalé par un encadré « Non vérifié ».

:::note[Doc non officielle]
Cette documentation est écrite par la communauté. Elle n'est liée ni à SFML, ni à Epitech.
:::
