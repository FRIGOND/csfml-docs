## What the program does

1. `sfRenderWindow_create` creates the window. It returns `NULL` on failure: **always check** the result.
2. The loop runs while `sfRenderWindow_isOpen` is true.
3. `sfRenderWindow_pollEvent` drains **all** pending events every frame.
4. `sfRenderWindow_clear` then `sfRenderWindow_display` draw the frame.
5. `sfRenderWindow_destroy` frees the window before exiting.

## Build

```sh
gcc -std=c11 -Wall -Wextra -o app main.c -lcsfml-graphics -lcsfml-window -lcsfml-system
```

The `-l` flags go **after** the source file. The migration notes are not translated yet (French only).
