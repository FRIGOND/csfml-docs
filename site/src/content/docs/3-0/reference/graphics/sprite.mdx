Un `sfSprite` affiche une `sfTexture`. **Le sprite garde un pointeur sur la texture, il ne la copie pas** : la texture doit rester vivante tant que le sprite est utilisé (vérifié avec valgrind : lire un sprite dont la texture est détruite donne `Invalid read`).

En-tête : `#include <CSFML/Graphics.h>` · bibliothèques : `-lcsfml-graphics -lcsfml-window -lcsfml-system`.

:::caution[Erreurs fréquentes]
- Passer `NULL` à `sfSprite_create` : `assert` sur le paquet Ubuntu, segfault sur un build Release maison.
- Détruire la texture avant le sprite.
:::

Même fonction en [2.6](/2-6/reference/graphics/sprite/) : `sfSprite_create()` n'a pas de paramètre.
