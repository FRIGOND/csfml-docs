## Les 5 premiers changements

| Ancien (2.6.1) | Nouveau (3.0.0) |
|---|---|
| `#include <SFML/Graphics.h>` | `#include <CSFML/Graphics.h>` |
| `sfBool`, `sfTrue`, `sfFalse` | `bool`, `true`, `false` |
| `sfRenderWindow_create(mode, titre, style, NULL)` | `sfRenderWindow_create(mode, titre, style, sfWindowed, NULL)` |
| `sfVideoMode m = {800, 600, 32}` | `sfVideoMode m = {{800, 600}, 32}` (l'ancienne forme compile avec `-Wmissing-braces`) |
| `sfSprite_create()` puis `sfSprite_setTexture` | `sfSprite_create(texture)` |
