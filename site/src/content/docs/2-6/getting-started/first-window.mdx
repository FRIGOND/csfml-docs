Ce programme ouvre une fenêtre noire de 800×600 pixels et la garde ouverte jusqu'à ce que tu la fermes.

<Example example="window/basic-window" version="2.6" />

## Compiler

```sh
gcc -std=c11 -Wall -Wextra -o app main.c -lcsfml-graphics -lcsfml-window -lcsfml-system
```

:::caution[Avertissement de dépréciation]
Avec `-Wall`, les headers 2.6.1 émettent `type is deprecated` (`Event.h`, `sfMouseWheelEvent`), même sans l'utiliser.
Avec `-Werror`, ajoute `-Wno-error=deprecated-declarations`.
:::
